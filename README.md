# Feriebudget Sommer 2027

Web-app til Alexandra, Arianny og Thomas, uge 26-31 i 2027.

## Nye funktioner
- Kamera/kvitteringsfoto
- GPS-position gemmes sammen med udgiften
- Knap **Se på kort** åbner den gemte position på OpenStreetMap
- Samlet rejsekort-liste over køb med GPS
- Sommer 2027-appikon medfølger

## iPhone
Appen skal ligge på HTTPS for at GPS virker. Åbn webadressen i Safari og vælg Del > Føj til hjemmeskærm. Første gang GPS bruges, skal placeringstilladelse accepteres.
